# ML Assignment 2 — Dry Bean Classification

## Problem statement
Build and evaluate five classification models to predict the bean variety from numerical measurements.

## Dataset description
Dataset: UCI Dry Bean Dataset. The target column is `Class`. The notebook checks the actual dimensions, missing values, duplicates, and class distribution after loading.

## Models used
- Logistic Regression
- Decision Tree
- K-Nearest Neighbors
- Gaussian Naive Bayes
- Support Vector Machine

## Evaluation metrics
The notebook calculates Accuracy, macro one-vs-rest AUC, macro Precision, macro Recall, macro F1, and Matthews Correlation Coefficient (MCC).

## Results and observations
Run `ML_Assignment_2.ipynb` and copy the actual values from `model_comparison.csv` into your report. Write observations based on your own measured results and confusion matrices. Do not invent scores or a winner.

## Run locally
1. Install packages: `pip install -r requirements.txt`
2. Run the notebook in Jupyter from this folder.
3. After training, run: `streamlit run app.py`
4. Upload the generated `test_data.csv` in the app.

## Files
- `ML_Assignment_2.ipynb`: end-to-end training and evaluation workflow
- `app.py`: Streamlit evaluation interface
- `requirements.txt`: required packages
- `model/`: saved model pipelines are generated by the notebook
- `test_data.csv`: generated by the notebook after training
